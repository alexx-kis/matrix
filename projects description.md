## 1. Advline

- сайт advline.ru, сделан на nextjs.
- информационный сайт маркетингового агентства
- анимации gsap, в том числе scroll driven
- список сотрудников берется из API (fetch)
- форма обратной связи отправляется по API в админку
- для состояния redux state
- ssr, проект запущен с помощью pm2 на сервере
- вся основная/текстовая/информационная часть захардкожена, так как не требуется часто обновлять
- соединение gsap анимации с 3d-моделью, при прокрутке страницы
- блог - страница со списком статей
- статьи полностью динамические. через админку коллеги заполняют текст статьи и смежную инфу, и страница сама появляется в списке. были сложности придумать, как парсить текст статьи из json так, чтобы рендерились разные необходимые элементы
- запущен (на проде)

- какие тут могли быть факапы/проблемы? я уже просто не помню
