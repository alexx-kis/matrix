# uglifying

- Uglifying — это исторически близкий к minification процесс, при котором JavaScript превращается в максимально компактный и плохо читаемый для человека вид
- само слово происходит от английского ugly — «некрасивый»
- на практике термин чаще всего связан с инструментом UglifyJS и исторической терминологией JavaScript-сборки

## чем uglifying отличается от minification

- эти термины очень сильно пересекаются, поэтому их легко перепутать
- `minification` — более общее понятие: уменьшение размера кода
- `uglifying` — более конкретная историческая терминология, связанная с преобразованием JavaScript в компактный и «некрасивый» вид
например, исходный код

```js
function calculateTotal(productPrice, productQuantity) {
    const totalPrice = productPrice * productQuantity;

    return totalPrice;
}
```
- после простого удаления лишних пробелов

```js
function calculateTotal(productPrice,productQuantity){const totalPrice=productPrice*productQuantity;return totalPrice}
```

- это уже minification в широком смысле
- если дополнительно сократить локальные имена

```js
function calculateTotal(e,t){return e*t}
```

- код становится ещё меньше и значительно менее читаемым
- именно такая идея исторически и называлась uglifying

## откуда появился термин

- раньше в JavaScript-экосистеме был очень популярен инструмент UglifyJS
- его задача заключалась в том, чтобы анализировать JavaScript и выполнять преобразования, позволяющие получить более компактный код
- отсюда и появился глагол uglify — «сделать JavaScript ugly»
- например, в старых проектах можно было встретить команды вроде

```
uglifyjs source.js -c -m
```

- где -c означал compression, а -m — mangling

## что такое mangling

- это важная часть темы
- mangling — переименование идентификаторов в более короткие имена

```js
function calculateTotal(productPrice, productQuantity) {
    const totalPrice = productPrice * productQuantity;

    return totalPrice;
}
```

- может превратиться в

```js
function calculateTotal(e,t){return e*t}
```

```
productPrice → e
productQuantity → t
```

- totalPrice вообще исчез, потому что его можно было заменить непосредственно выражением

```js
return e*t
```

- mangling особенно эффективен, когда в bundle тысячи переменных с длинными именами

## а что такое compression внутри minifier

- здесь возникает ещё одна тонкость терминологии
- в инструментах вроде UglifyJS слово compression не обязательно означает gzip или Brotli
- это оптимизация самого JavaScript-кода
- например, инструмент может увидеть

```js
const totalPrice = productPrice * productQuantity;
return totalPrice;
```

- и преобразовать это в

```js
return productPrice * productQuantity;
```

- это не сетевое сжатие файла
- это изменение самого JavaScript-кода с сохранением его поведения
- поэтому нужно различать

```
JavaScript optimization
        ↓
compression / transformations
        ↓
mangling
        ↓
minified JavaScript
        ↓
gzip / Brotli
        ↓
network transfer
```

## что используется сегодня

- термин uglifying сегодня встречается значительно реже, чем minification
- исторически важен UglifyJS, но современная экосистема использует другие инструменты
- например, Terser стал одним из наиболее распространённых инструментов для минификации JavaScript
- современные bundlers также умеют выполнять minification самостоятельно или подключать соответствующий инструмент
- поэтому на собеседовании лучше говорить так

- `Uglifying` — исторический термин для процесса преобразования JavaScript в более компактный и менее читаемый вид, обычно с помощью UglifyJS, включающий такие операции, как удаление лишнего кода, compression и mangling

- главное различие, которое нужно держать в голове
```
minification
    ↓
общее понятие уменьшения размера кода
```
```
uglifying
    ↓
историческое название процесса «сделать JavaScript ugly»
    ↓
UglifyJS
```
```
mangling
    ↓
сокращение имён идентификаторов
```
```
compression
    ↓
оптимизация самого JavaScript-кода
```
```
gzip / Brotli
    ↓
сетевое сжатие уже готового файла
```
- то есть uglifying не стоит воспринимать как совершенно отдельную современную технологию рядом с minification
- скорее это исторически сложившийся термин и название конкретного подхода/инструмента к минификации JavaScript
