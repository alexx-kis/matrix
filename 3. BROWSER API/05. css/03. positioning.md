# positioning

- **positioning** — это механизм CSS, который позволяет управлять положением элемента относительно обычного потока документа или другого элемента

- основное свойство — `position`

```css
.element {
  position: static;
}
```

- у `position` есть пять основных значений — `static`, `relative`, `absolute`, `fixed`, `sticky`

## `static`

- `static` — значение по умолчанию для большинства элементов

```css
.block {
  position: static;
}
```

- элемент находится в обычном потоке документа

- свойства `top`, `right`, `bottom`, `left` и `z-index` не перемещают обычный `static`-элемент

```css
.block {
  position: static;
  top: 50px;
}
```

- `top: 50px` здесь фактически ничего не изменит

## `relative`

- `relative` оставляет элемент в обычном потоке, но позволяет визуально сместить его относительно его исходного положения

```css
.element {
  position: relative;
  top: 20px;
  left: 30px;
}
```

- элемент визуально переместится на `30px` вправо и на `20px` вниз

- важный момент — **место элемента в обычном потоке сохраняется**

```
до:

┌─────────────┐
│   element   │
└─────────────┘

после смещения:

      ┌─────────────┐
      │   element   │
      └─────────────┘

место, которое элемент занимал в потоке, остаётся
```

- `relative` очень часто используется не столько для собственного смещения, сколько для создания **позиционированного родителя** для `absolute`

## `absolute`

- `absolute` полностью исключает элемент из обычного потока

```css
.element {
  position: absolute;
  top: 0;
  right: 0;
}
```

- другие элементы больше не учитывают его как обычный элемент

- главное правило — `absolute` позиционируется относительно ближайшего предка, который создаёт **positioning context**

- обычно таким предком делают элемент с `position: relative`

```html
<div class="card">
  <button class="close">×</button>
</div>
```

```css
.card {
  position: relative;
}

.close {
  position: absolute;
  top: 10px;
  right: 10px;
}
```

- `.close` будет расположен относительно `.card`

- `position: relative` у `.card` здесь нужен именно для создания точки отсчёта

## почему без `relative` возникает проблема

- если у родителя нет подходящего positioning context, `absolute` ищет ближайшего подходящего предка выше по DOM

- если такого предка нет, позиционирование происходит относительно initial containing block, который для типичных случаев можно воспринимать как область viewport/страницы

- поэтому распространённый паттерн выглядит так

```css
.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 0;
  right: 0;
}
```

## `top`, `right`, `bottom`, `left`

- эти свойства задают смещение позиционируемого элемента относительно соответствующих сторон его containing block

```css
.element {
  position: absolute;
  top: 20px;
  right: 30px;
}
```

- это означает, что верхняя и правая границы элемента будут отстоять от соответствующих границ containing block на указанные значения

- можно использовать и отрицательные значения

```css
.element {
  position: relative;
  top: -10px;
}
```

- элемент визуально поднимется на `10px`

## `fixed`

- `fixed` позиционирует элемент относительно viewport и исключает его из обычного потока

```css
.header {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}
```

- такой элемент остаётся на одном месте относительно окна браузера при прокрутке страницы

- типичные применения — fixed header, floating button, cookie banner, элементы навигации

```
┌─────────────────────────────┐
│          HEADER             │ ← fixed
├─────────────────────────────┤
│                             │
│        page content         │
│                             │
│                             │
└─────────────────────────────┘

scroll ↓

┌─────────────────────────────┐
│          HEADER             │ ← остаётся здесь
├─────────────────────────────┤
│       другой контент        │
│                             │
└─────────────────────────────┘
```

- как и `absolute`, `fixed` не занимает место в обычном потоке

## `sticky`

- `sticky` сочетает поведение обычного элемента и `fixed`

```css
.header {
  position: sticky;
  top: 0;
}
```

- пока элемент находится в пределах своей обычной позиции, он ведёт себя как элемент потока

- при прокрутке, когда он достигает значения `top: 0`, он начинает "прилипать" к верхней границе scrolling container

- при дальнейшем движении он остаётся закреплённым, пока не достигнет границы своего containing block

```
начало:

header
────────────
content
content
content

scroll ↓

────────────
header       ← прилип к top
────────────
content
content
```

- в отличие от `fixed`, sticky-элемент связан со своим контейнером

- например, sticky-заголовок внутри секции не будет бесконечно оставаться на экране после выхода из своей секции

## сравнение

| `position` | в потоке | относительно чего позиционируется                   | остаётся при scroll |
| ---------- | -------- | --------------------------------------------------- | ------------------- |
| `static`   | да       | обычный flow                                        | нет                 |
| `relative` | да       | собственное исходное положение                      | нет                 |
| `absolute` | нет      | containing block                                    | нет                 |
| `fixed`    | нет      | viewport или соответствующий fixed containing block | да                  |
| `sticky`   | да       | scrolling container + его границы                   | частично            |

## `absolute` и размеры

- у абсолютно позиционированного элемента есть интересная особенность — если явно не задать `width`, его ширина часто определяется содержимым или заданными ограничениями, а не растягивается так же, как у обычного block-level элемента

```css
.badge {
  position: absolute;
  top: 0;
  right: 0;
}
```

- поэтому при необходимости размер обычно задают явно или через `left` и `right`

```css
.panel {
  position: absolute;
  left: 0;
  right: 0;
}
```

- в таком случае элемент может растянуться между двумя сторонами containing block

## `inset`

- вместо четырёх свойств `top`, `right`, `bottom`, `left` можно использовать сокращённое свойство `inset`

```css
.element {
  position: absolute;
  inset: 10px;
}
```

- это эквивалентно

```css
.element {
  top: 10px;
  right: 10px;
  bottom: 10px;
  left: 10px;
}
```

- также можно задавать значения отдельно

```css
.element {
  position: absolute;
  inset: 0 20px;
}
```

- это аналогично shorthand для `top/right/bottom/left`

## `position` и `z-index`

- позиционирование часто используется вместе с `z-index`, чтобы управлять тем, какой элемент находится визуально поверх другого

```css
.modal {
  position: fixed;
  z-index: 100;
}
```

- но `z-index` имеет собственные правила, связанные со **stacking context**, поэтому просто сравнить два числа иногда недостаточно

- эту тему лучше рассматривать отдельно, когда будем разбирать `z-index`

## containing block

- один из самых важных терминов для понимания positioning — **containing block**

- это область, относительно которой рассчитываются размеры и координаты позиционируемого элемента

- для обычного `absolute` часто containing block создаётся ближайшим предком с подходящим позиционированием

```css
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 0;
  right: 0;
}
```

- здесь `.card` становится containing block для `.badge`

## частая ошибка

- неправильно считать, что `position: absolute` всегда позиционируется относительно родителя

- он позиционируется относительно **ближайшего подходящего предка**, а не обязательно непосредственного родителя

```html
<div class="outer">
  <div class="inner">
    <div class="item"></div>
  </div>
</div>
```

```css
.outer {
  position: relative;
}

.item {
  position: absolute;
  top: 0;
}
```

- `.item` будет позиционироваться относительно `.outer`, даже несмотря на наличие `.inner`

## что важно сказать на собеседовании

- `static` — обычное положение элемента в flow

- `relative` — элемент остаётся в flow, но может быть смещён и может создать containing block для `absolute`

- `absolute` — элемент исключается из flow и позиционируется относительно ближайшего подходящего containing block

- `fixed` — элемент исключается из flow и обычно позиционируется относительно viewport, поэтому остаётся на месте при прокрутке

- `sticky` — элемент остаётся частью flow и при прокрутке может "прилипать" к указанной границе своего scrolling container

- `top`, `right`, `bottom`, `left` и `inset` задают координаты/смещения позиционируемого элемента

- наиболее частый практический паттерн — `position: relative` на родителе и `position: absolute` на дочернем элементе для размещения бейджей, иконок, кнопок закрытия и декоративных элементов
