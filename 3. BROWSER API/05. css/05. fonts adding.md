# fonts adding

- в CSS шрифты можно использовать двумя основными способами — брать шрифт, который уже установлен у пользователя, или подключать внешний файл шрифта в проект

## системные шрифты

- браузер может использовать шрифты, которые уже установлены в операционной системе

```css
body {
  font-family: Arial, sans-serif;
}
```

- здесь `Arial` — предпочтительный шрифт, а `sans-serif` — fallback

- если `Arial` отсутствует, браузер попробует использовать любой доступный sans-serif шрифт

- обычно указывают несколько вариантов

```css
body {
  font-family: Inter, Arial, sans-serif;
}
```

- браузер проверяет их слева направо

## подключение собственного шрифта

- если нужного шрифта нет на компьютере пользователя, его можно добавить в проект через `@font-face`

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
}
```

- после этого шрифт можно использовать как обычный

```css
body {
  font-family: 'Inter', sans-serif;
}
```

- `@font-face` сообщает браузеру, откуда взять файл шрифта и под каким именем зарегистрировать его

## основные свойства `@font-face`

- `font-family` — имя, под которым шрифт будет использоваться в CSS

- `src` — источник файла шрифта

- `font-weight` — какой вес содержит конкретный файл

- `font-style` — обычный, italic и другие варианты

- `font-display` — определяет поведение текста во время загрузки шрифта

## разные начертания

- если проект использует несколько начертаний, обычно подключают отдельный файл для каждого веса

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
}

@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-bold.woff2') format('woff2');
  font-weight: 700;
  font-style: normal;
}
```

- теперь браузер сможет выбрать подходящий файл в зависимости от `font-weight`

```css
.title {
  font-family: 'Inter', sans-serif;
  font-weight: 700;
}
```

- браузер не должен искусственно делать обычный `400` жирным, если в проекте существует настоящий файл `700`

## `font-style`

- аналогично можно подключить italic

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-italic.woff2') format('woff2');
  font-weight: 400;
  font-style: italic;
}
```

```css
.quote {
  font-family: 'Inter', sans-serif;
  font-style: italic;
}
```

## форматы шрифтов

- наиболее важный современный формат — `WOFF2`

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter.woff2') format('woff2');
}
```

- `WOFF2` хорошо подходит для веба благодаря хорошему сжатию и поддержке современными браузерами

- также существует `WOFF`, но для современных проектов обычно предпочтителен `WOFF2`

- `TTF` и `OTF` — распространённые форматы шрифтов в целом, но для web обычно стараются отдавать оптимизированный `WOFF2`

## fallback

- при подключении собственного шрифта всё равно желательно указывать fallback

```css
body {
  font-family: 'Inter', Arial, sans-serif;
}
```

- если `Inter` не загрузился, браузер сможет использовать следующий вариант

- последний generic family вроде `sans-serif` особенно важен, потому что гарантирует выбор подходящего системного шрифта этого типа

## `font-display`

- `font-display` определяет, как браузер ведёт себя с текстом до загрузки web font

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter.woff2') format('woff2');
  font-display: swap;
}
```

- наиболее часто используемое значение — `swap`

- при `swap` браузер сначала может показать текст fallback-шрифтом, а после загрузки заменить его на web font

- это позволяет не оставлять пользователя без текста только потому, что шрифт ещё загружается

- также существуют `auto`, `block`, `fallback`, `optional`, но на практике `swap` встречается особенно часто

## variable fonts

- **variable font** позволяет хранить несколько вариантов начертания в одном файле

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-variable.woff2') format('woff2');
  font-weight: 100 900;
}
```

- теперь можно использовать разные значения веса

```css
.title {
  font-family: 'Inter', sans-serif;
  font-weight: 700;
}
```

```css
.text {
  font-family: 'Inter', sans-serif;
  font-weight: 400;
}
```

- при этом один файл может содержать диапазон весов от `100` до `900`

## подключение через внешний сервис

- шрифт также можно получать с внешнего сервиса, например Google Fonts

- обычно сервис предоставляет готовый `@import` или `<link>`

- для production-проектов важно учитывать производительность, приватность, доступность внешнего ресурса и необходимость дополнительных сетевых запросов

## preload

- критически важный шрифт можно предварительно загрузить через `<link rel="preload">`

```html
<link rel="preload" href="/fonts/inter.woff2" as="font" type="font/woff2" crossorigin />
```

- браузер получает сигнал, что этот ресурс нужен достаточно рано

- `preload` не следует использовать для всех шрифтов подряд, потому что чрезмерный preload создаёт конкуренцию за сетевые ресурсы

## unicode-range

- `unicode-range` позволяет указать, какие символы обслуживает конкретный файл шрифта

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-latin.woff2') format('woff2');
  unicode-range: U+0000-00FF;
}
```

- это может использоваться для разделения шрифта по наборам символов, например Latin и Cyrillic, чтобы браузер не загружал ненужный набор

## что происходит при использовании шрифта

- когда браузер встречает

```css
.title {
  font-family: 'Inter', sans-serif;
}
```

- он пытается найти `Inter`

- если `Inter` — web font, браузер загружает соответствующий файл, описанный через `@font-face`

- затем выбирается подходящий файл с учётом `font-weight`, `font-style` и других параметров

- если web font недоступен, используется следующий шрифт из списка

## важный нюанс — CORS

- если шрифт загружается с другого origin, сервер должен разрешать соответствующий cross-origin запрос

- иначе браузер может заблокировать загрузку ресурса из-за CORS

## что важно сказать на собеседовании

- для подключения собственного web font используется `@font-face`
- для современного веба обычно предпочтителен формат `WOFF2`
- разные веса и стили можно описать отдельными `@font-face` или использовать variable font
- `font-display: swap` позволяет сначала показать текст fallback-шрифтом, а затем заменить его загруженным шрифтом
- всегда полезно указывать fallback-шрифты
- `preload` можно использовать для действительно критичных шрифтов, но злоупотреблять им не стоит
- при использовании внешнего источника шрифтов нужно учитывать производительность и CORS
