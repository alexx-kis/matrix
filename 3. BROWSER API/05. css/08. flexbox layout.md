# flexbox layout technique

- **Flexbox** — это CSS-модель layout, предназначенная прежде всего для размещения элементов в **одном измерении**: в строке или в колонке

- Flexbox особенно удобен, когда нужно выстроить элементы в ряд, распределить свободное пространство, выровнять их по вертикали или горизонтали и сделать layout адаптивным

## flex container и flex items

- чтобы включить Flexbox, родителю задают `display: flex`

```css
.container {
  display: flex;
}
```

- после этого `.container` становится **flex container**

- его непосредственные дочерние элементы становятся **flex items**

```html
<div class="container">
  <div class="item"></div>
  <div class="item"></div>
  <div class="item"></div>
</div>
```

- Flexbox применяется только к непосредственным детям контейнера

## main axis и cross axis

- у flex-контейнера есть две оси

- **main axis** — главная ось, вдоль которой располагаются элементы

- **cross axis** — перпендикулярная ей ось

- по умолчанию

```css
.container {
  display: flex;
  flex-direction: row;
}
```

```
main axis →
┌─────┐ ┌─────┐ ┌─────┐
│  A  │ │  B  │ │  C  │
└─────┘ └─────┘ └─────┘
          ↑
       cross axis
```

- если изменить направление

```css
.container {
  display: flex;
  flex-direction: column;
}
```

```
main axis
   ↓
┌─────┐
│  A  │
└─────┘
┌─────┐
│  B  │
└─────┘
┌─────┐
│  C  │
└─────┘
```

- поэтому нельзя просто запомнить, что `justify-content` всегда отвечает за горизонтальное выравнивание, а `align-items` — за вертикальное

- их поведение определяется **осями**

## `flex-direction`

- определяет направление main axis

```css
.container {
  flex-direction: row;
}
```

- `row` — слева направо

```css
.container {
  flex-direction: row-reverse;
}
```

- `row-reverse` — справа налево

```css
.container {
  flex-direction: column;
}
```

- `column` — сверху вниз

```css
.container {
  flex-direction: column-reverse;
}
```

- `column-reverse` — снизу вверх

- значение по умолчанию — `row`

## `justify-content`

- управляет распределением flex items **вдоль main axis**

```css
.container {
  display: flex;
  justify-content: center;
}
```

- если `flex-direction: row`, это будет горизонтальное выравнивание

```
┌────────────────────────┐
│       A   B   C        │
└────────────────────────┘
```

- основные значения

```css
justify-content: flex-start;
justify-content: flex-end;
justify-content: center;
justify-content: space-between;
justify-content: space-around;
justify-content: space-evenly;
```

- `flex-start` — элементы в начале main axis

- `flex-end` — в конце

- `center` — по центру

- `space-between` — свободное пространство распределяется между элементами

```
A──────B──────C
```

- `space-around` — пространство распределяется вокруг каждого элемента

- `space-evenly` — равные промежутки между элементами и краями контейнера

## `align-items`

- управляет выравниванием flex items **по cross axis**

```css
.container {
  display: flex;
  align-items: center;
}
```

- при `flex-direction: row` это вертикальное выравнивание

```
┌────────────────────────┐
│                        │
│       A   B   C        │
│                        │
└────────────────────────┘
```

- основные значения

```css
align-items: stretch;
align-items: flex-start;
align-items: flex-end;
align-items: center;
align-items: baseline;
```

- значение по умолчанию — `stretch`

- `stretch` растягивает flex items по cross axis, если этому не мешают их размеры или другие ограничения

## `align-content`

- это свойство часто путают с `align-items`

- `align-items` выравнивает **items внутри flex line**

- `align-content` распределяет **сами flex lines**, когда их несколько

- поэтому `align-content` становится действительно заметным при использовании

```css
flex-wrap: wrap;
```

```css
.container {
  display: flex;
  flex-wrap: wrap;
  align-content: center;
}
```

- если все элементы помещаются в одну строку, `align-content` практически нечего распределять

## `flex-wrap`

- по умолчанию flex items стараются находиться в одной строке

```css
.container {
  display: flex;
  flex-wrap: nowrap;
}
```

- `nowrap` — значение по умолчанию

- если места недостаточно, элементы могут уменьшаться

- `wrap` разрешает перенос на следующую flex line

```css
.container {
  display: flex;
  flex-wrap: wrap;
}
```

```
A  B  C  D
E  F  G
```

- `wrap-reverse` переносит линии в обратном направлении по cross axis

## `gap`

- `gap` задаёт расстояние между flex items

```css
.container {
  display: flex;
  gap: 20px;
}
```

```
A ──20px── B ──20px── C
```

- можно отдельно задавать расстояние между строками и колонками

```css
.container {
  display: flex;
  row-gap: 10px;
  column-gap: 20px;
}
```

- для обычного расстояния между flex items `gap` обычно предпочтительнее использования `margin`

## свойства flex items

- часть свойств задаётся не контейнеру, а непосредственно его детям

- основные — `flex-grow`, `flex-shrink`, `flex-basis`, `flex`, `align-self`, `order`

## `flex-basis`

- `flex-basis` задаёт исходный размер элемента **по main axis**

```css
.item {
  flex-basis: 200px;
}
```

- если направление `row`, это примерно исходная ширина

- если `column`, это исходная высота

- `flex-basis` похож на `width` или `height`, но является именно частью flex-механизма

## `flex-grow`

- `flex-grow` определяет, может ли элемент получать дополнительное свободное пространство

```css
.item {
  flex-grow: 1;
}
```

- если несколько элементов имеют

```css
.item {
  flex-grow: 1;
}
```

- свободное пространство распределяется между ними пропорционально их коэффициентам

```
A: 1
B: 1
C: 1

→ свободное место делится примерно поровну
```

- если

```
A: 1
B: 2
```

- `B` получает в два раза большую долю свободного пространства

## `flex-shrink`

- `flex-shrink` определяет, насколько элемент может уменьшаться, когда места недостаточно

```css
.item {
  flex-shrink: 1;
}
```

- значение по умолчанию — `1`

- `flex-shrink: 0` запрещает элементу уменьшаться из-за нехватки места

```css
.item {
  flex-shrink: 0;
}
```

## `flex`

- `flex` — shorthand для

```
flex-grow
flex-shrink
flex-basis
```

- например

```css
.item {
  flex: 1;
}
```

- это распространённый способ сказать, что элементы должны делить доступное пространство

- более явно можно написать

```css
.item {
  flex-grow: 1;
  flex-shrink: 1;
  flex-basis: 0;
}
```

- `flex: 1` часто используют для создания равных по ширине элементов

```
┌───────┬────────┬───────┐
│   A   │   B    │   C   │
└───────┴────────┴───────┘
```

## `align-self`

- позволяет отдельному flex item переопределить `align-items` контейнера

```css
.container {
  display: flex;
  align-items: center;
}

.special {
  align-self: flex-start;
}
```

- остальные элементы будут выровнены по `center`, а `.special` — отдельно

## `order`

- `order` позволяет изменить визуальный порядок flex items

```css
.first {
  order: 2;
}

.second {
  order: 1;
}
```

- `.second` визуально окажется раньше `.first`

- важно помнить, что изменение `order` **не меняет порядок элементов в DOM**

- это может иметь значение для accessibility и клавиатурной навигации, поэтому использовать `order` для изменения логической структуры страницы нужно осторожно

## `flexbox` и `margin: auto`

- `margin: auto` внутри flex-контейнера имеет особое практическое применение

```css
.header {
  display: flex;
}

.navigation {
  margin-left: auto;
}
```

- свободное пространство слева от `.navigation` будет поглощено `auto` margin

```
Logo ─────────────── Navigation
```

- это очень распространённый способ прижать один элемент к противоположной стороне

## `min-width: 0`

- это важный практический нюанс Flexbox

- flex item по умолчанию может иметь `min-width: auto`, из-за чего длинный контент иногда не позволяет элементу сжаться так, как ожидается

```css
.content {
  min-width: 0;
}
```

- это особенно часто требуется для flex-элементов с длинным текстом, `overflow` или вложенными компонентами

- на собеседовании достаточно помнить, что `min-width: 0` часто решает проблему неожиданного горизонтального overflow внутри flex-контейнера

## flexbox и margin collapsing

- margin collapsing, характерный для обычного block flow, между flex items не происходит

- это ещё одна причина, почему `gap` и Flexbox часто удобнее для построения расстояний между элементами

## flexbox vs обычный block layout

- обычный block layout естественно располагает block-элементы вертикально

- Flexbox позволяет явно управлять направлением, распределением свободного пространства и выравниванием элементов

```
block:

A
B
C
```

```
flex row:

A  B  C
```

## flexbox vs grid

- Flexbox предназначен прежде всего для **одномерного layout**

```
A ─ B ─ C ─ D
```

- Grid предназначен для **двумерного layout**, когда одновременно важны строки и колонки

```
A  B  C
D  E  F
G  H  I
```

- это не жёсткое правило, потому что Flexbox тоже может создавать несколько строк через `wrap`, а Grid может использоваться для простых одномерных задач

- правильнее воспринимать это как основную концепцию: Flexbox управляет layout относительно одной оси, Grid — относительно двух

## типичный пример

```css
.toolbar {
  display: flex;
  align-items: center;
  gap: 16px;
}

.actions {
  margin-left: auto;
}
```

```html
<div class="toolbar">
  <div class="logo">Logo</div>
  <nav class="navigation">Navigation</nav>
  <div class="actions">Actions</div>
</div>
```

- `toolbar` создаёт flex-контейнер
- `align-items: center` выравнивает элементы по cross axis
- `gap` создаёт расстояние между элементами
- `margin-left: auto` забирает свободное пространство и прижимает `.actions` вправо

## что важно сказать на собеседовании

- Flexbox — это одномерная модель CSS layout
- `display: flex` превращает элемент во flex container, а его непосредственных детей — во flex items
- `flex-direction` определяет main axis
- `justify-content` работает вдоль main axis
- `align-items` работает вдоль cross axis
- `flex-wrap` разрешает перенос flex items на несколько линий
- `gap` задаёт расстояние между flex items
- `flex-grow` определяет распределение дополнительного свободного пространства
- `flex-shrink` определяет поведение при нехватке пространства
- `flex-basis` задаёт исходный размер по main axis
- `flex` — shorthand для `grow`, `shrink` и `basis`
- `align-self` позволяет отдельному item переопределить `align-items`
- `order` меняет визуальный порядок, но не DOM-порядок
- для двумерного layout чаще подходит CSS Grid, а для одномерного — Flexbox
