# pseudo-classes и pseudo-elements

- несмотря на похожие названия, **pseudo-class** и **pseudo-element** решают разные задачи
- pseudo-class описывает **состояние или положение существующего элемента**
- pseudo-element позволяет обратиться к **определённой виртуальной части элемента** или создать дополнительное содержимое

```
pseudo-class
элемент → какое сейчас состояние?

pseudo-element
элемент → какую его часть хотим стилизовать или что хотим добавить?
```

## pseudo-classes

- **pseudo-class** — это специальное ключевое слово после `:`, которое выбирает элемент в зависимости от его состояния, положения или некоторых условий

```css
button:hover {
  background: black;
}
```

- здесь `:hover` означает: выбрать `button`, над которым сейчас находится указатель мыши

- сам `button` уже существует в DOM

- `:hover` ничего нового не создаёт, а только изменяет условие, при котором применяется стиль

## основные pseudo-classes

### `:hover`

- применяется, когда указатель находится над элементом

```css
.menu-link:hover {
  text-decoration: underline;
}
```

- часто используется для интерактивных элементов

### `:active`

- соответствует моменту активации элемента, например во время нажатия кнопки мыши

```css
.submit-control:active {
  transform: translateY(1px);
}
```

- `:active` не означает «элемент уже был нажат»
- это именно состояние в момент активации

### `:focus`

- применяется, когда элемент получает focus

```css
.search-control:focus {
  outline: 2px solid blue;
}
```

- это особенно важно для клавиатурной навигации

### `:focus-visible`

- похож на `:focus`, но предназначен для случаев, когда браузер считает визуальное отображение focus особенно уместным, например при навигации с клавиатуры

```css
.search-control:focus-visible {
  outline: 2px solid blue;
}
```

- это часто предпочтительнее, чем полностью убирать стандартный `outline`

### `:disabled`

- выбирает отключённые элементы формы

```css
.submit-control:disabled {
  opacity: 0.5;
}
```

### `:checked`

- выбирает отмеченный checkbox или radio

```css
.option-control:checked {
  accent-color: blue;
}
```

### `:required` и `:optional`

- позволяют выбрать обязательные и необязательные элементы формы

```css
.form-field:required {
  border-color: red;
}
```

### `:valid` и `:invalid`

- позволяют стилизовать элементы формы в зависимости от результата встроенной HTML-валидации

```css
.email-control:invalid {
  border-color: red;
}

.email-control:valid {
  border-color: green;
}
```

## pseudo-classes положения

- часть pseudo-classes определяет положение элемента среди siblings

### `:first-child`

- выбирает элемент, который является первым дочерним элементом своего родителя

```html
<div>
  <p>one</p>
  <p>two</p>
</div>
```

```css
p:first-child {
  font-weight: bold;
}
```

- здесь первый `p` подходит под условие

### `:last-child`

```css
p:last-child {
  margin-bottom: 0;
}
```

- выбирается последний child

### `:nth-child()`

- позволяет выбрать элемент по его позиции

```css
.table-row:nth-child(2) {
  background: lightgray;
}
```

- это выберет второй child родителя

- можно использовать формулы:

```css
.table-row:nth-child(2n) {
  background: lightgray;
}
```

- здесь выбираются элементы с номерами `2`, `4`, `6`, `8` и так далее

- часто используется для zebra-striping таблиц

### `:nth-of-type()`

- похож на `:nth-child()`, но считает только элементы определённого типа

```html
<div>
  <span>label</span>
  <p>one</p>
  <p>two</p>
  <p>three</p>
</div>
```

```css
p:nth-of-type(2) {
  font-weight: bold;
}
```

- здесь будет выбран второй `p`

- наличие `span` перед ним не влияет на нумерацию `p`

- это важное отличие:

```
:nth-child()
    ↓
считает всех siblings

:nth-of-type()
    ↓
считает только элементы данного типа
```

## `:not()`

- `:not()` выбирает элементы, которые **не соответствуют** указанному селектору

```css
.card-link:not(.is-disabled) {
  cursor: pointer;
}
```

- здесь выбираются `.card-link`, у которых нет класса `.is-disabled`

- `:not()` особенно полезен для исключений, когда не хочется создавать отдельный селектор для каждого варианта

## `:is()`

- `:is()` позволяет объединить несколько вариантов селектора

```css
article :is(h2, h3, h4) {
  margin-bottom: 8px;
}
```

- вместо нескольких селекторов можно записать один

```css
article h2,
article h3,
article h4 {
  margin-bottom: 8px;
}
```

- важный нюанс: `:is()` учитывает specificity наиболее специфичного селектора внутри своих аргументов

## `:where()`

- `:where()` похож на `:is()`, но его specificity всегда равна `0`

```css
article :where(h2, h3, h4) {
  margin-bottom: 8px;
}
```

- это особенно удобно при создании базовых или библиотечных стилей, которые должны легко переопределяться

## `:has()`

- `:has()` позволяет выбирать элемент на основании того, что находится внутри него или рядом с ним
- его часто называют **parent selector**, хотя возможности шире простого выбора родителя

```css
.form-group:has(input:invalid) {
  border-color: red;
}
```

- здесь `.form-group` будет выбран, если внутри него есть `input`, который соответствует `:invalid`

- это очень важная современная возможность, потому что раньше CSS практически не позволял выбирать родителя на основании состояния ребёнка

## pseudo-elements

- **pseudo-element** обозначает виртуальный элемент или часть существующего элемента
- синтаксис обычно использует `::`

```css
.notice-box::before {
  content: '';
}
```

- `::before` не означает, что в HTML появился настоящий `<div>`
- это генерируемое содержимое, которое браузер визуально рассматривает как часть элемента

## `::before`

- создаёт pseudo-element перед содержимым элемента

```css
.notice-box::before {
  content: '→ ';
}
```

- HTML:

```html
<div class="notice-box">Continue</div>
```

- визуально получится примерно:

```
→ Continue
```

- без `content` pseudo-element `::before` обычно ничего не отображает

## `::after`

- работает аналогично, но создаёт pseudo-element после содержимого

```css
.notice-box::after {
  content: ' ✓';
}
```

- `::before` и `::after` особенно часто используют для декоративных элементов

```css
.notice-box::before {
  content: '';
  display: block;
  width: 8px;
  height: 8px;
  border-radius: 50%;
}
```

- например, таким способом можно создать декоративную точку, линию, уголок или фон без дополнительного HTML-элемента

## `::first-letter`

- позволяет стилизовать первую букву текста

```css
.article-copy::first-letter {
  font-size: 3rem;
  font-weight: 700;
}
```

- классический пример — большая первая буква в начале статьи

## `::first-line`

- позволяет стилизовать первую визуальную строку текста

```css
.article-copy::first-line {
  font-weight: 700;
}
```

- важно: это именно **визуальная строка**, а не первые символы HTML-текста
- при изменении ширины элемента граница первой строки может измениться

## `::selection`

- определяет внешний вид текста, который пользователь выделил

```css
.article-copy::selection {
  background: blue;
  color: white;
}
```

## `::placeholder`

- позволяет стилизовать placeholder у form controls

```css
.search-control::placeholder {
  color: gray;
}
```

- placeholder — это не обычное значение `value`, а подсказка, отображаемая пока пользователь не ввёл значение

## `::marker`

- позволяет стилизовать маркер элемента списка

```css
.task-item::marker {
  font-size: 1.2em;
}
```

- применяется, например, к `li` в `ul` или `ol`

## отличие `:` и `::`

- исторически pseudo-elements часто записывались с одним `:`
- современная запись использует `::` для pseudo-elements и `:` для pseudo-classes

```css
/* pseudo-class */
button:hover {
}

/* pseudo-element */
button::before {
}
```

- это помогает сразу понять, с чем мы имеем дело

- некоторые старые pseudo-elements вроде `::before` и `::after` браузеры также позволяют записывать через один `:`, но в современном коде лучше использовать `::`

## главное концептуальное отличие

```css
button:hover {
  color: red;
}
```

- `button` уже существует
- `:hover` описывает **состояние этого button**

```css
button::before {
  content: '→';
}
```

- `button` уже существует

- `::before` создаёт **виртуальную часть внутри визуального представления button**

- поэтому удобно запомнить:

```
:     → состояние / условие / положение

::    → виртуальная часть / генерируемое содержимое
```

## pseudo-element не является обычным DOM-элементом

- это важный момент для собеседования
- `::before` и `::after` не появляются как обычные элементы в HTML-коде

```html
<div class="notice-box">Text</div>
```

- JavaScript не может получить `::before` через обычный `querySelector('.notice-box::before')`
- это не означает, что pseudo-element вообще никак нельзя исследовать или изменить через JavaScript, но он не является обычным DOM-node

## когда использовать pseudo-elements

- pseudo-elements хорошо подходят для **декоративного содержимого**
- например, для линий, стрелок, декоративных фонов, маркеров, иконок, кавычек

```css
.quote-block::before {
  content: '“';
  font-size: 4rem;
}
```

- не стоит помещать через `::before` или `::after` важную информацию, без которой пользователь не сможет понять содержание страницы
- если информация семантически важна, лучше представить её настоящим HTML-элементом

## pseudo-class и pseudo-element вместе

- их можно комбинировать

```css
.action-link:hover::after {
  content: ' →';
}
```

- здесь сначала описывается состояние `:hover`

- затем выбирается pseudo-element `::after`

- также можно написать:

```css
.action-link::before {
  content: '';
}

.action-link:hover::before {
  transform: scaleX(1);
}
```

- то есть pseudo-element может иметь разные стили в зависимости от состояния основного элемента

## specificity

- pseudo-class увеличивает specificity как class selector

```
:hover
:focus
:nth-child()
:not(...)
```

- то есть они относятся к категории `C` в классической модели specificity

- pseudo-element относится к категории элементов

```
::before
::after
::first-letter
::first-line
```

- поэтому в общем случае:

```
.class
    ↓
:hover

::before
    ↓
меньшая specificity
```

- это полезно помнить при разборе конфликтов CSS

## что часто спрашивают на собеседовании

- **в чём разница между pseudo-class и pseudo-element**
- pseudo-class описывает состояние, положение или условие существующего элемента
- pseudo-element представляет виртуальную часть элемента или генерируемое содержимое

- **можно ли создать элемент через `::before`**
- визуально да, но это не обычный DOM-элемент и не замена семантической HTML-разметке

- **зачем нужен `content`**
- для `::before` и `::after` он обычно необходим, чтобы pseudo-element генерировался, при этом значение может быть пустой строкой `""`

- **чем отличаются `:nth-child()` и `:nth-of-type()`**
- `:nth-child()` считает всех детей, а `:nth-of-type()` считает только элементы соответствующего HTML-типа

- **зачем нужен `:has()`**
- он позволяет выбирать элемент с учётом наличия внутри него или рядом с ним элементов, соответствующих определённому условию

- **зачем нужен `:where()`**
- он позволяет группировать селекторы, но имеет нулевую specificity, поэтому такие правила легко переопределять
