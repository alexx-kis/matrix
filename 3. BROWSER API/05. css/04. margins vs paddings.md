# margins vs paddings

- `margin` и `padding` оба создают пространство вокруг содержимого, но находятся **по разные стороны границы элемента**

```
       margin
  ←──────────────→
┌──────────────────┐
│     border       │
│  ┌────────────┐  │
│  │  padding   │  │
│  │ ┌────────┐ │  │
│  │ │content │ │  │
│  │ └────────┘ │  │
│  └────────────┘  │
└──────────────────┘
```

- `padding` — пространство **между content и border**

- `margin` — пространство **снаружи border**, между элементом и соседними элементами

## padding

- `padding` увеличивает внутреннее пространство элемента

```css
.card {
  padding: 20px;
}
```

- содержимое `.card` будет находиться на расстоянии `20px` от его границы

```
┌──────────────────────┐
│      20px            │
│   ┌──────────────┐   │
│   │   content    │   │
│   └──────────────┘   │
│      20px            │
└──────────────────────┘
```

- `padding` является частью размеров элемента с точки зрения box model

- например, при

```css
.box {
  width: 200px;
  padding: 20px;
}
```

- при `box-sizing: content-box` фактическая ширина будет `240px`

```
200px content
+ 20px left padding
+ 20px right padding
= 240px
```

- при `box-sizing: border-box` заданная `width: 200px` уже включает content, padding и border

## margin

- `margin` создаёт внешнее пространство вокруг элемента

```css
.card {
  margin: 20px;
}
```

- соседние элементы будут находиться на расстоянии от `.card`

```
   20px margin
        ↓
┌──────────────┐
│     card     │
└──────────────┘
        ↑
   20px margin
```

- `margin` не является частью самого элемента в box model

- поэтому изменение `margin` меняет положение элемента относительно окружающих элементов, а `padding` меняет положение содержимого внутри элемента

## главное различие

- если нужно сделать **пространство внутри элемента**, используется `padding`

- если нужно сделать **пространство снаружи элемента**, используется `margin`

```css
.card {
  padding: 20px;
  margin: 30px;
}
```

```
    30px margin
↓               ↓
┌───────────────────┐
│    20px padding   │
│   ┌────────────┐  │
│   │  content   │  │
│   └────────────┘  │
└───────────────────┘
```

## стороны

- у обоих свойств можно задавать каждую сторону отдельно

```css
.box {
  margin-top: 10px;
  margin-right: 20px;
  margin-bottom: 30px;
  margin-left: 40px;
}
```

```css
.box {
  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 30px;
  padding-left: 40px;
}
```

## shorthand

- четыре значения записываются по часовой стрелке

```css
.box {
  margin: 10px 20px 30px 40px;
}
```

- порядок такой

```
top → right → bottom → left
```

- два значения означают

```css
.box {
  margin: 10px 20px;
}
```

- первое значение — `top` и `bottom`

- второе — `left` и `right`

```
10px  ← top/bottom
20px  ← left/right
```

- три значения

```css
.box {
  margin: 10px 20px 30px;
}
```

- означают

```
10px → top
20px → right + left
30px → bottom
```

- те же правила работают для `padding`

## `margin: auto`

- `margin: auto` часто используется для горизонтального центрирования block-элемента

```css
.container {
  width: 600px;
  margin: 0 auto;
}
```

- `auto` для левого и правого margin распределяет доступное свободное пространство поровну

```
свободное       свободное
пространство   пространство
     ↓             ↓
 ┌─────────────────┐
 │    container    │
 └─────────────────┘
```

- это не то же самое, что `text-align: center`

- `text-align` управляет выравниванием содержимого, а `margin: auto` — положением самого элемента

## margin collapse

- у `margin` существует важная особенность — **margin collapsing**

- вертикальные margins некоторых block-элементов могут схлопываться вместо обычного сложения

```css
.first {
  margin-bottom: 30px;
}

.second {
  margin-top: 20px;
}
```

- можно ожидать `50px`, но в обычном block flow расстояние между ними может составить `30px`

- берётся больший из двух margins

```
30px
20px
 ↓
30px итогового расстояния
```

- это называется **margin collapse**

- горизонтальные margins так не схлопываются

- также margin collapsing не происходит, например, между flex/grid items обычным способом

## padding не схлопывается

- `padding` никогда не ведёт себя как collapsing margin

```css
.first {
  padding-bottom: 30px;
}

.second {
  padding-top: 20px;
}
```

- эти внутренние пространства сохраняются независимо друг от друга

## background и margin

- `background` элемента распространяется на его content и padding, но не на margin

```css
.box {
  padding: 20px;
  margin: 20px;
  background: gray;
}
```

```
margin
  ↓
  ┌────────────────────┐
  │      background    │
  │   padding          │
  │   ┌────────────┐   │
  │   │  content   │   │
  │   └────────────┘   │
  └────────────────────┘
```

- область margin остаётся за пределами background элемента

## отрицательный margin

- `margin` может иметь отрицательное значение

```css
.box {
  margin-top: -20px;
}
```

- это может физически приблизить элемент к соседним элементам или привести к его перекрытию с ними

- у `padding` отрицательных значений быть не может

## `margin` или `gap`

- в современном layout часто возникает вопрос, использовать ли `margin` или `gap`

- для расстояния **между элементами flex/grid-контейнера** обычно предпочтительнее `gap`

```css
.list {
  display: flex;
  gap: 20px;
}
```

- вместо

```css
.item {
  margin-right: 20px;
}
```

- `gap` лучше выражает намерение — расстояние между элементами, а не внешний отступ конкретного элемента

## что важно сказать на собеседовании

- `padding` — внутреннее пространство между content и border
- `margin` — внешнее пространство за пределами border
- `padding` входит в box model элемента, а `margin` находится снаружи элемента
- `padding` не может быть отрицательным, `margin` может
- вертикальные margins некоторых block-элементов могут схлопываться
- `margin: 0 auto` часто используется для горизонтального центрирования block-элемента с заданной шириной
- для расстояния между flex/grid items обычно лучше использовать `gap`, если задача именно в задании промежутка между элементами
