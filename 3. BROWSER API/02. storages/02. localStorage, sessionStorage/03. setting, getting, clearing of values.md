# setting, getting, clearing of values

- оба storage имеют практически одинаковый API
- поэтому все, что мы сейчас рассмотрим для `localStorage`, работает и для `sessionStorage`

## 1. Setting - запись значения

- для записи используется метод:

```js
localStorage.setItem('theme', 'dark');
```

## 2. Getting - получение значения

- для чтения используется

```js
localStorage.getItem('theme');
```

- метод получает ключ, а возвращает соответствующее значение

```js
const savedTheme = localStorage.getItem('theme');
console.log(savedTheme); // dark
```

- если такого ключа нет, результат будет null
- это отличается от обычного объекта, где обращение к отсутствующему свойству обычно дает undefined

## 3. Clearing / removing - удаление значения

- здесь уже два разных действия, которые важно не путать

### удалить конкретное значение

```js
localStorage.removeItem('theme');
```

### очистить весь Storage

```js
localStorage.clear();
```

## для sessionStorage все то же самое

```js
sessionStorage.setItem('step', '2');

const currentStep = sessionStorage.getItem('step');

sessionStorage.removeItem('step');

sessionStorage.clear();
```

## важный момент: значения - только строки

- все установленные значения будут конвертированы в строки

```js
localStorage.setItem('age', 25);

const storedAge = localStorage.getItem('age');

console.log(typeof storedAge); // string

localStorage.setItem('isLoggedIn', true);
const loginState = localStorage.getItem('isLoggedIn'); // "true"
```

## сохранение объектов

- напрямую сохранять объект нельзя
- чтобы сохранить объект, нужно сначала конвертировать его в строку:

```js
localStorage.setItem('user', JSON.stringify(userData));
```

- затем при чтении распарсить его обратно:

```js
const storedUser = localStorage.getItem('user');

const parsedUser = JSON.parse(storedUser);
```
