# media

- в HTML под media обычно понимают элементы для работы с изображениями, аудио и видео
- основные элементы — `<img>`, `<picture>`, `<audio>`, `<video>`, а также `<source>`

## изображения — `<img>`

- `<img>` вставляет изображение в документ

```html
<img src="./images/avatar.jpg" alt="User avatar" />
```

- `src` указывает путь к изображению

- `alt` содержит текстовое описание и важен для accessibility, а также отображается, если изображение не загрузилось

- размеры лучше явно задавать, чтобы браузер заранее зарезервировал место и не создавал layout shift

```html
<img src="./images/product.jpg" alt="Red backpack" width="800" height="600" />
```

- через CSS изображение обычно адаптируют так

```css
img {
  max-width: 100%;
  height: auto;
}
```

## responsive images

- если для разных экранов нужны разные размеры изображения, используется `srcset`

```html
<img
  src="./images/photo-800.jpg"
  srcset="./images/photo-400.jpg 400w, ./images/photo-800.jpg 800w, ./images/photo-1200.jpg 1200w"
  sizes="(max-width: 600px) 100vw, 800px"
  alt="Mountain landscape"
/>
```

- `srcset` предоставляет браузеру несколько вариантов изображения

- `sizes` сообщает, какой размер изображения предполагается в layout

- браузер сам выбирает подходящий ресурс

- это позволяет не загружать огромную картинку на маленький экран

## `<picture>`

- `<picture>` используется, когда нужно дать браузеру разные изображения в зависимости от условий

```html
<picture>
  <source media="(max-width: 600px)" srcset="./images/mobile.jpg" />
  <source media="(min-width: 601px)" srcset="./images/desktop.jpg" />

  <img src="./images/desktop.jpg" alt="City view" />
</picture>
```

- `picture` особенно полезен, когда мобильная и desktop-версии изображения отличаются не только размером, но и содержанием или соотношением сторон

- отличие от `srcset` можно запомнить так

- `srcset` — разные варианты одного изображения для выбора подходящего ресурса

- `<picture>` — возможность задавать разные источники и условия их выбора

---

## `<audio>`

- `<audio>` предназначен для воспроизведения звука

```html
<audio controls src="./audio/track.mp3"></audio>
```

- `controls` показывает стандартные элементы управления браузера

- можно указать несколько форматов через `<source>`

```html
<audio controls>
  <source src="./audio/track.mp3" type="audio/mpeg" />
  <source src="./audio/track.ogg" type="audio/ogg" />
</audio>
```

- браузер выберет поддерживаемый формат

---

## `<video>`

- `<video>` предназначен для воспроизведения видео

```html
<video controls width="640" height="360" poster="./images/preview.jpg">
  <source src="./video/movie.mp4" type="video/mp4" />
  <source src="./video/movie.webm" type="video/webm" />
</video>
```

- `controls` — элементы управления
- `poster` — изображение, показываемое до начала воспроизведения
- `width` и `height` задают размеры области видео
- `<source>` позволяет предоставить несколько форматов

---

## основные атрибуты `<video>`

```html
<video controls autoplay muted loop playsinline>
  <source src="./video/background.mp4" type="video/mp4" />
</video>
```

- `autoplay` — автоматическое воспроизведение

- `muted` — отключает звук

- `loop` — повторяет видео

- `playsinline` — позволяет воспроизводить видео непосредственно внутри страницы на поддерживаемых мобильных устройствах

- на практике `autoplay` часто используется вместе с `muted`, потому что браузеры ограничивают автоматическое воспроизведение видео со звуком

---

## `<source>`

- `<source>` сам по себе ничего не отображает
- он предоставляет альтернативные media-ресурсы для `<audio>` или `<video>`

```html
<video controls>
  <source src="./video/content.webm" type="video/webm" />
  <source src="./video/content.mp4" type="video/mp4" />
</video>
```

- браузер выбирает подходящий источник

---

## accessibility

- для изображений обязательно нужно осмысленно использовать `alt`

```html
<img src="./images/search.svg" alt="Search" />
```

- если изображение декоративное и не несёт смысловой информации, `alt` должен быть пустым

```html
<img src="./images/decorative-line.svg" alt="" />
```

- для видео могут использоваться субтитры через `<track>`

```html
<video controls>
  <source src="./video/interview.mp4" type="video/mp4" />

  <track src="./subtitles/interview-en.vtt" kind="subtitles" srclang="en" label="English" />
</video>
```

- файл `.vtt` содержит временные интервалы и текст субтитров

---

## lazy loading

- изображения можно загружать лениво

```html
<img src="./images/gallery-item.jpg" alt="Gallery item" loading="lazy" />
```

- `loading="lazy"` позволяет браузеру отложить загрузку изображения, пока оно не понадобится поблизости от viewport

- это особенно полезно для больших страниц с большим количеством изображений

- для критически важного изображения lazy loading обычно не нужен

---

## что важно помнить

- `<img>` — изображение
- `<picture>` — разные источники изображения в зависимости от условий
- `srcset` — несколько вариантов изображения для выбора браузером
- `<audio>` — звук
- `<video>` — видео
- `<source>` — альтернативный media-источник
- `<track>` — текстовые дорожки, например субтитры
- `alt` — текстовая альтернатива изображения
- `poster` — превью видео
- `loading="lazy"` — отложенная загрузка изображения
- `controls` — стандартные элементы управления media
