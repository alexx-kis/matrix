# html tables

- HTML-таблицы используются для представления **табличных данных**, где информация организована в строки и столбцы
- таблица должна использоваться именно для данных, а не для построения layout страницы

## базовая структура

```html
<table>
  <tr>
    <td>John</td>
    <td>25</td>
  </tr>
  <tr>
    <td>Jane</td>
    <td>30</td>
  </tr>
</table>
```

- `<table>` — таблица

- `<tr>` — table row, строка

- `<td>` — table data cell, обычная ячейка

- логическая структура здесь такая

```text
table
├── tr
│   ├── td
│   └── td
│
└── tr
    ├── td
    └── td
```

---

# заголовки столбцов — `<th>`

- для заголовков используются `<th>`, а не `<td>`

```html
<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>John</td>
    <td>25</td>
  </tr>
</table>
```

- `<th>` имеет семантику заголовочной ячейки

- по умолчанию браузер обычно отображает её жирным шрифтом и центрирует, но главное здесь именно **семантика**, а не внешний вид

- использование `<th>` позволяет браузеру, screen reader и другим инструментам понять, какие ячейки являются заголовками данных

---

# `scope`

- у `<th>` есть важный атрибут `scope`, который указывает, какие ячейки описывает данный заголовок

- для заголовка столбца

```html
<th scope="col">Name</th>
```

- для заголовка строки

```html
<th scope="row">John</th>
```

- например

```html
<table>
  <tr>
    <th scope="col">Name</th>
    <th scope="col">Age</th>
    <th scope="col">City</th>
  </tr>

  <tr>
    <th scope="row">John</th>
    <td>25</td>
    <td>Belgrade</td>
  </tr>
</table>
```

- здесь `Name`, `Age`, `City` описывают соответствующие столбцы

- `John` является заголовком конкретной строки

- `scope` особенно полезен для доступности, потому что помогает связать данные с их заголовками

---

# `<caption>`

- `<caption>` задаёт название или описание таблицы

```html
<table>
  <caption>
    Employees
  </caption>

  <tr>
    <th scope="col">Name</th>
    <th scope="col">Department</th>
  </tr>

  <tr>
    <td>John</td>
    <td>Frontend</td>
  </tr>
</table>
```

- `<caption>` должен быть непосредственным дочерним элементом `<table>`
- это не то же самое, что `<h2>` над таблицей
- `<caption>` семантически связывается именно с таблицей

# группировка строк

- HTML позволяет разделить строки таблицы на три логические части

```html
<table>
  <thead>
    ...
  </thead>

  <tbody>
    ...
  </tbody>

  <tfoot>
    ...
  </tfoot>
</table>
```

- `<thead>` содержит строки заголовка

- `<tbody>` содержит основное содержимое

- `<tfoot>` содержит итоговые или завершающие строки

- полноценный пример

```html
<table>
  <caption>
    Sales
  </caption>

  <thead>
    <tr>
      <th scope="col">Product</th>
      <th scope="col">Quantity</th>
      <th scope="col">Price</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Keyboard</td>
      <td>2</td>
      <td>$100</td>
    </tr>

    <tr>
      <td>Mouse</td>
      <td>3</td>
      <td>$60</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <th scope="row">Total</th>
      <td>5</td>
      <td>$160</td>
    </tr>
  </tfoot>
</table>
```

- эти элементы не предназначены просто для визуального разделения
- они дают браузеру и другим инструментам дополнительную структуру таблицы

# `<colgroup>` и `<col>`

- если нужно описать свойства целых столбцов, существуют `<colgroup>` и `<col>`

```html
<table>
  <colgroup>
    <col />
    <col class="numeric-column" />
  </colgroup>

  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>

  <tr>
    <td>John</td>
    <td>25</td>
  </tr>
</table>
```

- `<col>` представляет один столбец или группу столбцов
- например, можно применить CSS к определённому столбцу

```css
.numeric-column {
  text-align: right;
}
```

- `<colgroup>` особенно полезен, когда нужно задать свойства колонок без добавления одинакового класса в каждую ячейку

---

# объединение ячеек

- ячейки можно объединять по горизонтали с помощью `colspan`

```html
<tr>
  <th colspan="2">Personal information</th>
</tr>
```

- `colspan="2"` означает, что ячейка занимает пространство двух столбцов

- например

```html
<table>
  <tr>
    <th colspan="2">User</th>
  </tr>

  <tr>
    <td>John</td>
    <td>25</td>
  </tr>
</table>
```

- `rowspan` делает аналогичное по вертикали

```html
<tr>
  <th rowspan="2">John</th>
  <td>Frontend</td>
</tr>

<tr>
  <td>JavaScript</td>
</tr>
```

- здесь ячейка `John` занимает две строки

---

# `colspan` и `rowspan` на практике

```html
<table>
  <tr>
    <th>Name</th>
    <th colspan="2">Contact</th>
  </tr>

  <tr>
    <td>John</td>
    <td>Email</td>
    <td>Phone</td>
  </tr>
</table>
```

- логически это выглядит примерно так

```text
┌──────┬───────────────┐
│ Name │    Contact    │
├──────┼───────┬───────┤
│ John │ Email │ Phone │
└──────┴───────┴───────┘
```

- здесь `Contact` занимает два столбца благодаря `colspan="2"`

# сложные заголовки и `headers`

- `scope` хорошо работает для простых таблиц
- если таблица имеет сложную структуру заголовков, можно явно связать ячейки данных с заголовками через `headers` и `id`

```html
<table>
  <tr>
    <th id="name">Name</th>
    <th id="frontend">Frontend</th>
    <th id="backend">Backend</th>
  </tr>

  <tr>
    <th id="john">John</th>
    <td headers="john frontend">Yes</td>
    <td headers="john backend">No</td>
  </tr>
</table>
```

- `headers` содержит `id` заголовочных ячеек, которые относятся к конкретной ячейке данных
- это особенно актуально для сложных таблиц, где связь между ячейкой и её заголовком нельзя однозначно определить только по положению

# стилизация таблиц

- HTML отвечает за структуру таблицы, а CSS — за её внешний вид

```css
table {
  border-collapse: collapse;
}

th,
td {
  border: 1px solid black;
  padding: 8px;
}
```

- `border-collapse: collapse` объединяет соседние границы ячеек в одну

- без него таблица по умолчанию использует модель `separate`, при которой границы ячеек рассматриваются отдельно

```css
table {
  border-collapse: separate;
}
```

- у `border-collapse` есть два основных значения: `collapse` и `separate`

# таблицы и responsive design

- таблицы часто представляют проблему на узких экранах, потому что содержимое может не помещаться по ширине
- распространённый подход — дать таблице горизонтально прокручиваться внутри контейнера

```html
<div class="table-wrapper">
  <table>
    ...
  </table>
</div>
```

```css
.table-wrapper {
  overflow-x: auto;
}
```

- это обычно лучше, чем пытаться превратить каждую ячейку в произвольный layout
- конкретное решение зависит от характера данных и требований интерфейса

---

# таблица не для layout

- исторически таблицы использовались для построения расположения элементов страницы

```html
<table>
  <tr>
    <td>Sidebar</td>
    <td>Main content</td>
  </tr>
</table>
```

- сейчас это считается неправильным использованием `<table>`

- таблица сообщает браузеру, что перед ним **набор взаимосвязанных табличных данных**

- для layout используются CSS Grid, Flexbox и другие CSS-механизмы

- например, если нужно расположить sidebar и content рядом, это задача CSS layout, а не HTML table

---

# важный нюанс: пустые ячейки

- если определённая ячейка таблицы не содержит значения, это не означает, что её нужно удалять из разметки
- структура таблицы должна сохраняться

```html
<tr>
  <td>John</td>
  <td></td>
  <td>Belgrade</td>
</tr>
```

- отсутствие `<td>` изменит структуру строки и может нарушить соответствие между столбцами

- если отсутствие значения имеет определённый смысл, иногда лучше явно представить его, например `—`, в зависимости от требований интерфейса

---

# доступность таблиц

- для простых таблиц важно как минимум корректно использовать `<th>` и `<td>`

- `<caption>` может дать таблице понятное название

- `scope` помогает определить связь заголовков с данными

- для сложных таблиц могут понадобиться `headers` и `id`

- например

```html
<table>
  <caption>
    Employee salaries
  </caption>

  <thead>
    <tr>
      <th scope="col">Employee</th>
      <th scope="col">Salary</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <th scope="row">John</th>
      <td>$5000</td>
    </tr>
  </tbody>
</table>
```

- здесь структура данных понятна не только визуально, но и семантически

# элементы таблицы — что помнить

```text
<table>
│
├── caption
│
├── colgroup
│   └── col
│
├── thead
│   └── tr
│       └── th
│
├── tbody
│   └── tr
│       ├── th
│       └── td
│
└── tfoot
    └── tr
        └── td / th
```

- `<table>` — таблица
- `<caption>` — её название
- `<thead>` — заголовочная часть
- `<tbody>` — основная часть
- `<tfoot>` — итоговая часть
- `<tr>` — строка
- `<th>` — заголовочная ячейка
- `<td>` — ячейка данных
- `<colgroup>` / `<col>` — описание столбцов

# что важно знать для собеседования

- `<table>` предназначен для табличных данных, а не для построения layout
- `<tr>` представляет строку
- `<td>` представляет обычную ячейку данных
- `<th>` представляет заголовок строки или столбца
- `scope="col"` связывает заголовок с колонкой, `scope="row"` — со строкой
- `<caption>` задаёт название таблицы
- `<thead>`, `<tbody>` и `<tfoot>` группируют строки по их назначению
- `colspan` объединяет ячейку по горизонтали, `rowspan` — по вертикали
- `<colgroup>` и `<col>` позволяют описывать столбцы
- для сложных таблиц связь между заголовками и данными можно задавать через `headers` + `id`
- CSS отвечает за внешний вид таблицы, например `border-collapse`, `padding`, `border` и responsive-поведение
- для layout вместо таблиц используются CSS Grid или Flexbox
