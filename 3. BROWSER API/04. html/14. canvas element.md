# `<canvas>` element

- `<canvas>` — HTML-элемент, предоставляющий область, в которой JavaScript может рисовать графику
- в отличие от SVG, canvas работает как **растровый холст**: после рисования браузер не хранит отдельные фигуры как DOM-элементы

## базовый пример

```html
<canvas id="drawing-area" width="500" height="300"></canvas>
```

- `width` и `height` здесь задают **размер внутреннего bitmap canvas**, а не просто CSS-размер

- чтобы рисовать, сначала получают rendering context

```js
const drawingCanvas = document.querySelector('#drawing-area');
const drawingContext = drawingCanvas.getContext('2d');
```

- `getContext('2d')` предоставляет API для двумерного рисования

---

# рисование

- например, прямоугольник

```js
drawingContext.fillStyle = 'blue';
drawingContext.fillRect(50, 40, 200, 100);
```

- `fillStyle` задаёт цвет заливки

- `fillRect(x, y, width, height)` рисует заполненный прямоугольник

- координаты начинаются с верхнего левого угла

```
(0, 0) ───────────────► x
  │
  │
  │
  ▼
  y
```

---

# path

- для более сложных фигур используется path

```js
drawingContext.beginPath();
drawingContext.moveTo(50, 150);
drawingContext.lineTo(150, 50);
drawingContext.lineTo(250, 150);
drawingContext.closePath();

drawingContext.stroke();
```

- `beginPath()` начинает новый путь
- `moveTo()` перемещает виртуальный указатель
- `lineTo()` добавляет линию
- `closePath()` замыкает путь
- `stroke()` рисует контур

---

# canvas и DOM

- SVG хранит фигуры как отдельные элементы

```html
<svg>
  <circle cx="50" cy="50" r="20"></circle>
</svg>
```

- canvas после рисования не создаёт отдельный DOM-элемент для круга

- для браузера это просто изменённое изображение внутри `<canvas>`

- поэтому нельзя сделать что-то вроде

```js
drawingCanvas.querySelector('circle');
```

- такого `circle` внутри canvas нет

---

# canvas vs SVG

| Canvas                                              | SVG                                          |
| --------------------------------------------------- | -------------------------------------------- |
| растровая графика                                   | векторная графика                            |
| рисование через JavaScript API                      | элементы представлены в DOM                  |
| после рисования фигуры не являются DOM-элементами   | каждая фигура может быть отдельным элементом |
| удобно для большого количества динамической графики | удобно для интерактивных отдельных объектов  |
| игры, графики, обработка изображений                | иконки, схемы, диаграммы                     |

- canvas часто выбирают для игр, графиков, визуализаций и работы с большим количеством динамических объектов
- SVG чаще удобнее для интерфейсной графики, где отдельными объектами нужно управлять через CSS или DOM

# размер canvas

- есть важное различие между HTML-атрибутами и CSS

```html
<canvas width="800" height="400"></canvas>
```

- здесь bitmap имеет размер `800 × 400`

- а если сделать только

```css
canvas {
  width: 800px;
  height: 400px;
}
```

- CSS изменит отображаемый размер, но не внутреннее разрешение bitmap
- из-за этого изображение может стать размытым

---

# accessibility

- canvas сам по себе не предоставляет такую же структуру, как обычный HTML или SVG

- поэтому важную информацию не стоит передавать исключительно через canvas без альтернативного представления

- можно добавить fallback-контент

```html
<canvas width="400" height="200"> Sales chart showing growth from January to June </canvas>
```

- содержимое внутри `<canvas>` используется как fallback для случаев, когда canvas недоступен

---

# другие context API

- кроме `2d` существуют другие типы rendering context
- наиболее известные — `2d`, `webgl`, `webgl2`

```js
const graphicsCanvas = document.querySelector('#drawing-area');
const webglContext = graphicsCanvas.getContext('webgl');
```

- WebGL позволяет использовать GPU для более сложной 2D/3D-графики

---

# что важно для собеседования

- `<canvas>` — область для программного рисования
- для рисования обычно используется JavaScript и `getContext('2d')`
- canvas хранит результат как bitmap, а не как набор DOM-элементов
- координатная система начинается с `(0, 0)` в левом верхнем углу
- `width` и `height` HTML-атрибутов определяют внутреннее разрешение canvas
- CSS-размер и внутреннее разрешение — разные вещи
- canvas подходит для игр, визуализаций, графиков и большого количества динамических объектов
- главное отличие от SVG — SVG сохраняет графические элементы как DOM-структуру, а canvas — нет
