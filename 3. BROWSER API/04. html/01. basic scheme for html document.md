# basic scheme for HTML document

- HTML-документ — это обычный текстовый файл, который браузер читает и преобразует в структуру DOM, а затем использует эту структуру для отображения страницы
- обычно HTML-файл имеет расширение `.html`
- минимальная структура HTML-документа выглядит так

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>My page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
  </body>
</html>
```

## `<!DOCTYPE html>`

- `<!DOCTYPE html>` называется **doctype declaration**
- это не HTML-тег, а специальное объявление, которое сообщает браузеру, какую модель обработки HTML нужно использовать
- современный HTML использует именно такую короткую форму

```html
<!DOCTYPE html>
```

- исторически у HTML были разные версии и гораздо более длинные DOCTYPE-декларации
- сейчас для обычного HTML-документа достаточно `<!DOCTYPE html>`
- важно понимать, что DOCTYPE **не говорит браузеру "это HTML5" напрямую**, а включает современный standards mode
- если DOCTYPE отсутствует или указан некорректно, браузер может перейти в **quirks mode**, где некоторые правила работают ради совместимости со старым вебом

---

## `<html>`

- `<html>` — корневой элемент HTML-документа
- внутри него находятся два основных раздела — `<head>` и `<body>`

```html
<html>
  <head>
    ...
  </head>

  <body>
    ...
  </body>
</html>
```

- у `<html>` обычно указывают атрибут `lang`

```html
<html lang="en"></html>
```

- `lang` сообщает язык содержимого документа
- например, для русского текста

```html
<html lang="ru"></html>
```

- для сербского

```html
<html lang="sr"></html>
```

- это полезно для screen reader, поисковых систем, браузеров и других инструментов, которые должны понимать язык страницы
- `lang` не переводит страницу автоматически

---

## `<head>`

- `<head>` содержит **метаданные документа** и информацию, необходимую браузеру, но не является основной видимой частью страницы
- например, сюда помещают кодировку, заголовок страницы, подключение CSS, мета-теги и другие настройки

```html
<head>
  <meta charset="UTF-8" />
  <title>My page</title>
</head>
```

- содержимое `<head>` обычно не отображается непосредственно внутри страницы
- однако некоторые элементы `<head>` влияют на то, как страница отображается и работает

### основные элементы `<head>`

```html
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>My page</title>
  <link rel="stylesheet" href="styles.css" />
</head>
```

- `<meta charset="UTF-8">` задаёт кодировку документа

- `<meta name="viewport">` управляет настройками viewport на мобильных устройствах

- `<title>` задаёт название страницы

- `<link>` позволяет подключать внешние ресурсы, например CSS

---

## `<meta charset="UTF-8">`

- браузеру необходимо знать, как интерпретировать последовательность байтов файла как символы
- `UTF-8` — наиболее распространённая кодировка для современных веб-страниц

```html
<meta charset="UTF-8" />
```

- благодаря этому браузер правильно понимает символы вроде

```text
Hello
Привет
Привет 😊
こんにちは
```

- если кодировка файла и указанная кодировка не совпадают, текст может отображаться неправильно

---

## `<title>`

- `<title>` задаёт название HTML-документа

```html
<title>Frontend Interview</title>
```

- это название может отображаться во вкладке браузера

- также оно используется браузером и другими инструментами, например при работе с закладками

- `<title>` находится внутри `<head>`, а не `<body>`

```html
<head>
  <title>Frontend Interview</title>
</head>
```

- при этом `<title>` — не заголовок, который пользователь видит внутри самой страницы
- для видимого заголовка страницы обычно используется `<h1>`

```html
<title>Frontend Interview</title>
```

```html
<h1>Frontend Interview</h1>
```

- это два разных элемента с разным назначением

---

## `<body>`

- `<body>` содержит основное содержимое HTML-документа, которое пользователь видит и с которым взаимодействует

```html
<body>
  <h1>Hello</h1>
  <p>Welcome to my page</p>
  <button>Click me</button>
</body>
```

- здесь находятся заголовки, текст, изображения, ссылки, формы, таблицы и другие элементы страницы

- условно можно представить HTML-документ так

```text
HTML document
│
├── DOCTYPE
│
└── html
    │
    ├── head
    │   ├── meta
    │   ├── title
    │   └── link
    │
    └── body
        ├── h1
        ├── p
        ├── img
        ├── button
        └── ...
```

## что происходит после загрузки HTML

- браузер получает HTML-текст

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Example</title>
  </head>
  <body>
    <h1>Hello</h1>
    <p>Text</p>
  </body>
</html>
```

- затем браузер разбирает HTML и строит из него DOM

```text
Document
└── html
    ├── head
    │   ├── meta
    │   └── title
    │
    └── body
        ├── h1
        │   └── "Hello"
        │
        └── p
            └── "Text"
```

- DOM — это объектное представление HTML-документа, с которым JavaScript может работать
- например, JavaScript может найти `<h1>` и изменить его содержимое

```js
const headingElement = document.querySelector('h1');

headingElement.textContent = 'Hello, JavaScript';
```

- поэтому HTML можно воспринимать как исходное описание структуры документа, а DOM — как структуру, которую браузер построил на его основе

## что нужно запомнить для собеседования

- `<!DOCTYPE html>` — включает современный standards mode
- `<html>` — корневой элемент документа
- `lang` — указывает основной язык содержимого документа
- `<head>` — метаданные и ресурсы страницы
- `<meta charset="UTF-8">` — задаёт кодировку документа
- `<title>` — название документа, например для вкладки браузера
- `<body>` — основное содержимое страницы
- HTML-файл не является DOM сам по себе — браузер парсит HTML и создаёт DOM
- отсутствие корректного DOCTYPE может привести браузер в quirks mode
- `<title>` и `<h1>` — разные вещи: первый относится к метаданным документа, второй является видимым заголовком содержимого

### типичный вопрос на собеседовании

- **что произойдёт, если убрать `<!DOCTYPE html>`**
- браузер всё равно попытается отобразить страницу, но может включить quirks mode
- в quirks mode браузер использует исторические правила совместимости, поэтому поведение некоторых HTML и CSS-конструкций может отличаться от standards mode
- поэтому современный HTML-документ практически всегда начинается с `<!DOCTYPE html>`
