# meta tags

- `<meta>` — это элемент с метаинформацией о HTML-документе, которая не отображается как обычное содержимое страницы

- такие данные используются браузером, поисковиками, соцсетями и другими системами

- `<meta>` обычно размещают внутри `<head>`

```html
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
</head>
```

## `charset`

- задаёт кодировку документа

```html
<meta charset="UTF-8" />
```

- `UTF-8` позволяет корректно отображать большинство используемых символов, включая кириллицу

---

## `viewport`

- определяет, как страница должна отображаться на устройствах с разной шириной экрана

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

- `width=device-width` говорит использовать ширину viewport, равную ширине устройства

- `initial-scale=1.0` задаёт начальный масштаб страницы

- для responsive-сайтов этот meta tag практически стандартен

---

## `description`

- задаёт краткое описание страницы

```html
<meta name="description" content="Frontend development courses and articles" />
```

- описание может использоваться поисковыми системами как текст сниппета
- это не гарантия того, что поисковик покажет именно этот текст

---

## `robots`

- позволяет задавать инструкции для поисковых роботов

```html
<meta name="robots" content="noindex, nofollow" />
```

- `noindex` — не индексировать страницу

- `nofollow` — не следовать ссылкам на странице

- этот meta tag относится к управлению поисковой индексацией, а не к безопасности страницы

---

## `http-equiv`

- `http-equiv` позволяет задать некоторые директивы, связанные с поведением браузера

```html
<meta http-equiv="refresh" content="30" />
```

- в данном случае браузер может обновлять страницу через указанное количество секунд

- `http-equiv` существует, но многие HTTP-заголовки предпочтительно задавать непосредственно сервером через HTTP headers, а не через `<meta>`

---

## Open Graph

- Open Graph — набор meta tags, используемый социальными сетями и другими сервисами при создании превью страницы

```html
<meta property="og:title" content="Frontend Course" />
<meta property="og:description" content="Learn frontend development" />
<meta property="og:image" content="https://example.com/preview.jpg" />
<meta property="og:url" content="https://example.com/course" />
```

- `og:title` — заголовок превью

- `og:description` — описание

- `og:image` — изображение

- `og:url` — канонический URL страницы

- Open Graph особенно важен, когда ссылками делятся в социальных сетях или мессенджерах

---

## Twitter/X cards

- для некоторых платформ используются дополнительные meta tags для управления карточкой ссылки

```html
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="Frontend Course" />
<meta name="twitter:description" content="Learn frontend development" />
<meta name="twitter:image" content="https://example.com/preview.jpg" />
```

- конкретная платформа может использовать собственные правила обработки этих данных

---

## `theme-color`

- позволяет указать предпочтительный цвет интерфейса браузера на поддерживаемых устройствах

```html
<meta name="theme-color" content="#ffffff" />
```

- например, браузер может использовать этот цвет для элементов своего интерфейса вокруг страницы

---

## `author`

- можно указать автора документа

```html
<meta name="author" content="Frontend Team" />
```

- технически это допустимо, но для большинства современных приложений этот meta tag не является критически важным

---

## важный момент

- `<meta>` не предназначен для отображаемого содержимого страницы
- для SEO нельзя просто добавить множество `meta keywords` и ожидать улучшения ранжирования

```html
<meta name="keywords" content="html, css, javascript" />
```

- `keywords` сегодня практически не имеет значения для основных поисковых систем

---

# что важно для собеседования

- `<meta>` хранит метаинформацию документа и обычно находится в `<head>`
- `charset` задаёт кодировку
- `viewport` необходим для корректного responsive-поведения
- `description` задаёт описание страницы для поисковых систем
- `robots` управляет некоторыми правилами индексации
- `og:*` используется для превью страницы при публикации ссылки
- `theme-color` может влиять на цвет интерфейса браузера
- `http-equiv` позволяет задать некоторые браузерные директивы, но HTTP headers часто являются предпочтительным местом для соответствующих настроек
- `<meta>` не заменяет HTTP-заголовки, например для `Content-Security-Policy` и других серверных политик
