# text formatting, paragraphs

- в HTML текст не просто хранится на странице, а размечается специальными элементами, которые сообщают браузеру смысл и структуру этого текста
- для абзацев используется `<p>`, для заголовков — `<h1>`–`<h6>`, а для смыслового форматирования текста существуют элементы вроде `<strong>`, `<em>`, `<mark>` и другие

## абзацы — `<p>`

- `<p>` означает **paragraph**, то есть абзац

```html
<p>This is the first paragraph</p>
<p>This is the second paragraph</p>
```

- браузер воспринимает это как два отдельных абзаца

- по умолчанию браузер добавляет между ними вертикальный отступ

- важно понимать, что `<p>` описывает **структуру и смысл текста**, а не просто визуальный отступ

```html
<p>First paragraph</p>
<p>Second paragraph</p>
```

- это правильнее, чем пытаться сделать два абзаца с помощью `<br>`

---

## перенос строки — `<br>`

- `<br>` означает **line break**, то есть принудительный перенос строки

```html
<p>
  First line<br />
  Second line
</p>
```

- результат будет примерно таким

```text
First line
Second line
```

- `<br>` не создаёт новый абзац

- он только говорит браузеру начать следующую строку

- поэтому эти варианты имеют разный смысл

```html
<p>First paragraph</p>
<p>Second paragraph</p>
```

- здесь два абзаца

```html
<p>
  First line<br />
  Second line
</p>
```

- здесь один абзац с переносом строки

- типичный пример, где `<br>` уместен — адрес или стихотворение

```html
<address>
  Main Street 10<br />
  Belgrade<br />
  Serbia
</address>
```

- использовать множество `<br>` для создания вертикальных отступов считается плохой практикой
- для визуальных отступов используется CSS

---

# заголовки

- HTML предоставляет шесть уровней заголовков

```html
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
```

- `<h1>` — самый высокий уровень заголовка

- `<h6>` — самый низкий

- эти элементы создают **иерархию документа**

```text
h1
├── h2
│   ├── h3
│   └── h3
│
└── h2
    └── h3
```

- например

```html
<h1>Frontend development</h1>

<h2>HTML</h2>
<p>HTML defines the structure of a web page</p>

<h2>CSS</h2>
<p>CSS controls presentation and layout</p>

<h2>JavaScript</h2>
<p>JavaScript adds behavior and interactivity</p>
```

- здесь `<h1>` является заголовком всей страницы
- три `<h2>` являются заголовками отдельных разделов

---

## важный нюанс с размером заголовков

- по умолчанию браузер визуально делает `<h1>` крупнее `<h2>`, `<h2>` крупнее `<h3>` и так далее
- однако **уровень заголовка определяется не его размером**
- HTML-элемент выбирается исходя из структуры документа, а внешний вид можно независимо изменить через CSS

```html
<h2 class="large-heading">HTML</h2>
```

```css
.large-heading {
  font-size: 40px;
}
```

- `<h2>` может выглядеть визуально крупнее `<h1>`, и это не меняет его семантический уровень
- поэтому нельзя выбирать `<h1>` просто потому, что нужен большой текст

---

# семантическое форматирование

- HTML предоставляет элементы, которые сообщают браузеру и другим инструментам **значение текста**
- это отличается от простого изменения внешнего вида

## `<strong>`

- `<strong>` обозначает текст с повышенной важностью

```html
<p><strong>Warning:</strong> This action cannot be undone</p>
```

- по умолчанию браузер обычно отображает `<strong>` жирным

```text
Warning: This action cannot be undone
```

- но главное значение `<strong>` — не жирный шрифт, а **важность содержимого**

---

## `<em>`

- `<em>` обозначает **emphasis**, то есть смысловое выделение или акцент

```html
<p>You <em>must</em> read this document</p>
```

- браузер обычно отображает `<em>` курсивом

- но снова важно не путать семантику и внешний вид

- `<em>` означает смысловой акцент, а не просто "сделай текст курсивным"

---

## `<b>`

- `<b>` используется для привлечения внимания к тексту без придания ему особой важности

```html
<p>Available in <b>three colors</b></p>
```

- по умолчанию текст будет жирным

- при этом `<b>` не означает "это важно" в том же смысле, что `<strong>`

- поэтому

```html
<strong>Important information</strong>
```

- и

```html
<b>Product name</b>
```

- имеют разный семантический смысл, даже если визуально оба могут выглядеть жирными

---

## `<i>`

- `<i>` используется для текста, который выделяется по определённой причине, например для терминов, иностранных слов или обозначений

```html
<p>The term <i>frontend</i> is widely used</p>
```

- по умолчанию браузер обычно показывает его курсивом
- `<i>` не означает просто "сделай курсив"
- для смыслового акцента используется `<em>`

---

# `<u>`

- `<u>` представляет текст с визуальным подчёркиванием или специальной аннотацией

```html
<p>This is <u>underlined text</u></p>
```

- по умолчанию браузер добавляет подчёркивание

- `<u>` не следует использовать просто потому, что хочется подчеркнуть обычный текст

- особенно на веб-страницах нужно учитывать, что пользователи привыкли воспринимать подчёркнутый текст как ссылку

---

# `<s>`

- `<s>` обозначает текст, который больше не является актуальным или корректным

```html
<p><s>$100</s> $70</p>
```

- здесь старое значение `$100` больше не актуально

- `<s>` отличается от `<del>`, несмотря на внешнее сходство

---

# `<del>` и `<ins>`

- `<del>` обозначает удалённый текст

```html
<p>The price is <del>$100</del> $70</p>
```

- `<ins>` обозначает добавленный текст

```html
<p>The price is <del>$100</del> <ins>$70</ins></p>
```

- эти элементы особенно полезны при представлении изменений документа

- отличие можно запомнить так

```text
<s>    текст больше не актуален
<del>  текст был удалён
<ins>  текст был добавлен
```

---

# `<mark>`

- `<mark>` обозначает текст, который нужно выделить или подсветить в текущем контексте

```html
<p>Search result: <mark>JavaScript</mark></p>
```

- браузер по умолчанию обычно отображает его с подсветкой

- хороший пример — результаты поиска, где совпавшая часть текста визуально выделяется

---

# `<small>`

- `<small>` обозначает текст, который является второстепенным или менее значимым

```html
<p>
  Product price
  <small>including taxes</small>
</p>
```

- по умолчанию браузер уменьшает размер текста
- однако семантически `<small>` означает не просто "маленький шрифт"

---

# `<sub>` и `<sup>`

- `<sub>` используется для нижнего индекса

```html
<p>H<sub>2</sub>O</p>
```

- результат

```text
H₂O
```

- `<sup>` используется для верхнего индекса

```html
<p>x<sup>2</sup></p>
```

- результат

```text
x²
```

- это удобно для химических формул, математических выражений и других подобных обозначений

---

# `<code>`

- `<code>` используется для обозначения небольшого фрагмента программного кода

```html
<p>Use <code>querySelector()</code> to find an element</p>
```

- браузер обычно отображает его моноширинным шрифтом

- если нужно показать большой блок кода, обычно используется комбинация `<pre>` и `<code>`

```html
<pre><code>const result = 10 + 20;</code></pre>
```

- `<code>` сообщает о том, что содержимое является кодом
- `<pre>` сохраняет форматирование текста, включая пробелы и переносы строк

---

# `<pre>`

- `<pre>` означает **preformatted text**
- содержимое этого элемента отображается с сохранением пробелов и переносов строк

```html
<pre>
first line
    second line
        third line
</pre>
```

- отступы внутри `<pre>` становятся частью отображаемого текста

- это отличается от обычного HTML-текста

```html
<p>first second third</p>
```

- обычные последовательные пробелы в HTML-тексте браузер обычно схлопывает

---

# схлопывание пробелов

- это один из важных нюансов HTML

```
<p>Hello    world</p>
```

- браузер обычно отобразит

```text
Hello world
```

- несколько последовательных обычных пробелов в HTML-тексте обычно воспринимаются как один пробельный интервал

- аналогично переносы строк в исходном HTML сами по себе обычно не создают визуальный перенос

```
<p>
  Hello
  world
</p>
```

- браузер обычно покажет

```text
Hello world
```

- если нужно сохранить такие пробелы и переносы, можно использовать `<pre>` или управлять поведением через CSS `white-space`

---

# `<span>`

- `<span>` — универсальный **строчный контейнер** для небольшого фрагмента текста или другого inline-содержимого

```html
<p>This is <span>some text</span></p>
```

- сам по себе `<span>` практически не сообщает никакого смысла
- его часто используют вместе с CSS или JavaScript

```html
<p>Hello, <span class="username">Alex</span></p>
```

- например, CSS может изменить внешний вид именно этого фрагмента

```css
.username {
  font-weight: bold;
}
```

- в отличие от `<strong>`, `<em>`, `<mark>` и других семантических элементов, `<span>` сам по себе не говорит, **что означает** выделенный текст

---

# `<div>` и текст

- `<div>` — универсальный блочный контейнер
- его можно использовать для группировки элементов

```html
<div>
  <h2>HTML</h2>
  <p>HTML defines document structure</p>
</div>
```

- `<div>` не является специальным элементом для форматирования текста
- он используется тогда, когда нет более подходящего семантического элемента

---

# визуальное форматирование через CSS

- HTML отвечает прежде всего за **структуру и смысл**

- CSS отвечает прежде всего за **визуальное представление**

- например, не стоит использовать `<b>` только потому, что нужен определённый внешний вид

```html
<p><strong>Important</strong></p>
```

```css
strong {
  color: red;
  font-size: 20px;
}
```

- HTML здесь сообщает, что текст важен

- CSS определяет, как эта важность будет визуально представлена

- аналогично не стоит создавать отступы с помощью большого количества `<br>`

```html
<br />
<br />
<br />
```

- вместо этого используется CSS

```css
.section {
  margin-bottom: 40px;
}
```

# что важно знать для собеседования

- `<p>` используется для абзацев, а не просто для создания вертикального отступа
- `<br>` создаёт перенос строки, но не новый абзац
- `<h1>`–`<h6>` формируют иерархию заголовков
- визуальный размер элемента не определяет его семантический уровень
- `<strong>` означает важность, а `<b>` в общем случае только привлекает внимание
- `<em>` означает смысловой акцент, а `<i>` используется для текста, выделенного по специальной причине
- `<del>` обозначает удалённый текст, а `<s>` — текст, который больше не актуален
- `<ins>` обозначает добавленный текст
- `<mark>` используется для смысловой подсветки
- `<sub>` и `<sup>` используются для индексов
- `<code>` обозначает программный код, а `<pre>` сохраняет пробелы и переносы строк
- обычные последовательные пробелы в HTML-тексте схлопываются
- HTML должен описывать структуру и смысл, а CSS — внешний вид
- `<span>` и `<div>` являются универсальными контейнерами, но сами по себе почти не добавляют семантики
