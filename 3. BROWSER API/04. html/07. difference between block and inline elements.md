# difference between block and inline elements

- главное различие — **как элемент участвует в потоке документа и сколько места по ширине он занимает**

## block elements

- `block`-элемент обычно начинается с новой строки и занимает всю доступную ширину родителя

```html
<div>Block 1</div>
<div>Block 2</div>
```

```
Block 1
Block 2
```

- типичные block-элементы — `div`, `p`, `h1`–`h6`, `section`, `article`, `header`, `footer`, `main`, `ul`, `ol`, `li`

- для block-элементов обычно нормально работают `width`, `height`, `margin`, `padding`

```css
.block-box {
  width: 300px;
  height: 100px;
  margin: 20px;
  padding: 10px;
}
```

---

## inline elements

- `inline`-элемент не начинает новую строку и занимает только пространство, необходимое его содержимому

```html
<p>Hello <span>world</span> and <a href="/">link</a></p>
```

- `span` и `a` находятся внутри той же строки, пока хватает места

- типичные inline-элементы — `span`, `a`, `strong`, `em`, `b`, `i`, `small`

- `width` и `height` у обычного inline-элемента не работают так, как у block-элемента

- вертикальные `margin` и `padding` у inline тоже имеют особенности и не изменяют layout так же, как у block

---

## главное отличие

|                     | `block`               | `inline`              |
| ------------------- | --------------------- | --------------------- |
| новая строка        | да                    | нет                   |
| ширина по умолчанию | доступная ширина      | по содержимому        |
| `width` / `height`  | работают              | обычно не применяются |
| примеры             | `div`, `p`, `section` | `span`, `a`, `strong` |

---

## `inline-block`

- `inline-block` сочетает поведение обоих вариантов

```css
.inline-box {
  display: inline-block;
  width: 200px;
  height: 50px;
}
```

- элемент остаётся в строке как `inline`, но получает возможность нормально задавать `width` и `height` как у block

```html
<span class="inline-box">First</span> <span class="inline-box">Second</span>
```

```
[ First ] [ Second ]
```

---

## важный нюанс

- HTML-тег сам по себе не навсегда определяет layout-поведение элемента
- его `display` можно изменить через CSS

```css
span {
  display: block;
}

div {
  display: inline;
}
```

- поэтому на собеседовании правильнее говорить не «`div` всегда block», а «по умолчанию `div` имеет `display: block`»
