# SVG

- SVG — **Scalable Vector Graphics**, формат для описания векторной графики с помощью XML-разметки
- в HTML SVG используется для иконок, логотипов, схем, графиков и другой графики, которая должна хорошо масштабироваться

## базовый SVG

```html
<svg width="100" height="100" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" fill="blue" />
</svg>
```

- `<svg>` — корневой контейнер

- `<circle>` — круг

- `cx`, `cy` — координаты центра

- `r` — радиус

- `fill` — цвет заливки

- SVG не хранит изображение как набор пикселей, поэтому увеличение размера не приводит к обычной потере качества

---

# `viewBox`

- один из самых важных атрибутов SVG — `viewBox`

```html
<svg width="200" height="100" viewBox="0 0 100 50">...</svg>
```

- `viewBox` задаёт внутреннюю систему координат SVG

```text
viewBox="minX minY width height"
```

- в примере внутренняя область имеет размер `100 × 50`, а отображается как `200 × 100`

- благодаря этому графику можно масштабировать без изменения координат её элементов

- важно не путать `width` и `height` с `viewBox`

- `width` и `height` задают размер отображения

- `viewBox` задаёт внутреннюю систему координат

---

# основные SVG-элементы

- SVG содержит различные графические примитивы

```html
<svg viewBox="0 0 200 100">
  <rect x="10" y="10" width="50" height="30" />
  <circle cx="100" cy="30" r="20" />
  <line x1="140" y1="10" x2="190" y2="50" />
</svg>
```

- основные элементы — `<rect>`, `<circle>`, `<ellipse>`, `<line>`, `<polygon>`, `<polyline>`, `<path>`

- `<path>` особенно важен, потому что позволяет описывать сложные произвольные формы

```html
<svg viewBox="0 0 100 100">
  <path d="M 10 80 L 50 20 L 90 80 Z" />
</svg>
```

- атрибут `d` содержит команды построения пути

---

# inline SVG

- SVG можно непосредственно написать внутри HTML

```html
<button type="button" aria-label="Search">
  <svg viewBox="0 0 24 24" aria-hidden="true">
    <circle cx="11" cy="11" r="7" />
    <line x1="16" y1="16" x2="21" y2="21" />
  </svg>
</button>
```

- преимущество inline SVG — его элементы доступны DOM и их можно стилизовать через CSS

```css
button svg {
  width: 24px;
  height: 24px;
}

button svg circle,
button svg line {
  stroke: currentColor;
}
```

- `currentColor` позволяет SVG использовать значение CSS-свойства `color` родительского элемента

---

# SVG как внешний файл

- SVG можно подключить аналогично обычному изображению

```html
<img src="./icons/logo.svg" alt="Company logo" />
```

- в таком случае SVG не становится частью DOM страницы

- стилизовать отдельные внутренние элементы SVG через CSS страницы напрямую нельзя

- это удобно для изображений, которые не требуют изменения отдельных частей через CSS или JavaScript

---

# `<use>`

- SVG позволяет переиспользовать уже определённую графику через `<use>`

```html
<svg style="display: none">
  <symbol id="icon-star" viewBox="0 0 24 24">
    <path d="..." />
  </symbol>
</svg>

<svg aria-hidden="true">
  <use href="#icon-star"></use>
</svg>
```

- такой подход часто используется в SVG icon systems
- одна иконка определяется один раз и затем переиспользуется в разных местах

---

# SVG и CSS

- SVG-элементы могут стилизоваться через CSS

```html
<svg class="status-icon" viewBox="0 0 24 24">
  <circle cx="12" cy="12" r="10" />
</svg>
```

```css
.status-icon {
  width: 24px;
  height: 24px;
  fill: none;
  stroke: currentColor;
  stroke-width: 2;
}
```

- часто используемые свойства — `fill`, `stroke`, `stroke-width`, `opacity`

- `fill` отвечает за заливку

- `stroke` — за обводку

---

# SVG и accessibility

- если SVG декоративный и не несёт информации, его можно скрыть от screen reader

```html
<svg aria-hidden="true">...</svg>
```

- если SVG является самостоятельным содержательным изображением, ему нужно предоставить доступное название

```html
<svg role="img" aria-labelledby="chart-title" viewBox="0 0 100 100">
  <title id="chart-title">Sales growth</title>
  ...
</svg>
```

- для обычной иконки внутри кнопки часто достаточно доступного названия самой кнопки и `aria-hidden="true"` у SVG

```html
<button type="button" aria-label="Close">
  <svg aria-hidden="true" viewBox="0 0 24 24">...</svg>
</button>
```

# SVG vs raster

| SVG                                                    | PNG/JPEG                                  |
| ------------------------------------------------------ | ----------------------------------------- |
| векторный                                              | растровый                                 |
| хорошо масштабируется                                  | при увеличении теряет качество            |
| обычно хорошо подходит для иконок и логотипов          | хорошо подходит для фотографий            |
| можно управлять элементами через CSS/JS при inline SVG | отдельные элементы изображения недоступны |
| описывается XML-подобной структурой                    | хранит пиксели                            |

- SVG не означает автоматически маленький размер файла
- сложный SVG с большим количеством `path` может быть довольно тяжёлым

---

# что важно для собеседования

- SVG — векторный формат, который можно использовать непосредственно в HTML
- `viewBox` задаёт внутреннюю систему координат и является ключевым для масштабирования
- `width` и `height` задают отображаемый размер
- `<path>` позволяет создавать сложные формы
- inline SVG является частью DOM и может управляться через CSS и JavaScript
- SVG через `<img>` не позволяет странице напрямую управлять его внутренними элементами
- `fill` отвечает за заливку, `stroke` — за обводку
- `currentColor` позволяет наследовать цвет из CSS
- `aria-hidden="true"` подходит для декоративного SVG
- SVG особенно хорошо подходит для иконок, логотипов и другой масштабируемой графики
