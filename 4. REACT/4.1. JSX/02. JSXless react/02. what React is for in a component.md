### зачем `React` нужен в компоненте

- в старом React `React` в компоненте был нужен не столько самому компоненту, сколько **механизму преобразования JSX в JavaScript**

- когда мы писали компонент

```jsx
import React from 'react';

function Welcome() {
  return <h1>Hello</h1>;
}
```

- казалось, что `React` нигде не используется

- но JSX

```jsx
<h1>Hello</h1>
```

- до React 17 преобразовывался примерно в

```js
React.createElement('h1', null, 'Hello');
```

- поэтому `React` был нужен, чтобы вызвать `React.createElement`, который создавал **React element** — обычный JavaScript-объект, описывающий, что React должен отрисовать

- сам компонент при этом можно представить как функцию, которая возвращает такое описание UI

```text
компонент
   ↓
JSX
   ↓
React.createElement(...)
   ↓
React element
   ↓
React использует его для построения своего дерева
   ↓
рендеринг в DOM
```

### важный нюанс

- `React` и компонент — это не одно и то же

- компонент — это наша функция, например

```jsx
function Welcome() {
  return <h1>Hello</h1>;
}
```

- `React` — это библиотека, предоставляющая механизмы, на которых работает React-приложение

- поэтому на собеседовании хороший ответ будет таким:

- **в старых версиях React импорт `React` в компоненте был необходим потому, что JSX компилировался в вызовы `React.createElement`, даже если мы сами нигде явно не обращались к `React`**
