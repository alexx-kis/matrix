### как JSX превращается в JavaScript

- JSX — это **синтаксис для описания UI**, который браузер сам по себе не понимает

- поэтому перед выполнением JSX должен быть преобразован в обычный JavaScript специальным инструментом, например Babel

### простой пример

- мы пишем

```jsx
const element = <h1>Hello</h1>;
```

- в старом React, до React 17, JSX преобразовывался примерно в

```js
const element = React.createElement('h1', null, 'Hello');
```

- здесь происходит важная вещь: `<h1>Hello</h1>` превращается не в DOM-элемент, а в **React element**

- `React.createElement()` создаёт JavaScript-объект, который описывает будущий элемент

- концептуально результат можно представить примерно так

```js
{
  type: "h1",
  props: {
    children: "Hello"
  }
}
```

- это ещё **не настоящий `<h1>` в браузерном DOM**

- React получает это описание и уже на следующем этапе решает, что нужно сделать с реальным DOM

### что происходит с атрибутами

- например, такой JSX

```jsx
const element = (
  <button className='primary' disabled>
    Click me
  </button>
);
```

- старый transform превращает его примерно в

```js
const element = React.createElement(
  'button',
  {
    className: 'primary',
    disabled: true,
  },
  'Click me',
);
```

- JSX-атрибуты становятся `props`, а содержимое элемента становится `children`

### что происходит с компонентами

- особенно важно понимать, что JSX может содержать не только HTML-подобные теги, но и компоненты

```jsx
const element = <Welcome name='Alex' />;
```

- это превращается примерно в

```js
const element = React.createElement(Welcome, {
  name: 'Alex',
});
```

- здесь `Welcome` не является строкой, потому что это JavaScript-переменная, содержащая компонент

- в итоге React получает информацию примерно такого смысла:

```
type → компонент Welcome
props → { name: "Alex" }
```

### а что происходит после React 17

- начиная с React 17 появился новый JSX transform

- поэтому

```jsx
const element = <h1>Hello</h1>;
```

- больше не обязан превращаться именно в

```js
React.createElement('h1', null, 'Hello');
```

- вместо этого современный transform использует специальные функции из `react/jsx-runtime`, концептуально примерно так

```js
import { jsx } from 'react/jsx-runtime';

const element = jsx('h1', {
  children: 'Hello',
});
```

- конкретный сгенерированный код зависит от используемого инструмента и его настроек, поэтому на собеседовании лучше говорить **«примерно преобразуется в»**, а не утверждать, что результат всегда выглядит именно так

### главное, что нужно понимать

- JSX **не превращается непосредственно в DOM**

- цепочка выглядит так:

```
JSX
 ↓
JSX transform
 ↓
JavaScript
 ↓
React elements
 ↓
React выполняет reconciliation
 ↓
изменяется Browser DOM
```

- для старого React ключевой момент — JSX превращался в вызовы `React.createElement`

- для современного React — используется новый JSX transform и `react/jsx-runtime`

- поэтому JSX — это в первую очередь **удобный синтаксис**, позволяющий описывать React elements более читаемо, чем вручную писать вызовы функций вроде `React.createElement()`
